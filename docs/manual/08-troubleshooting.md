# 困ったときは

まず環境を確認してください。コマンドパレットで `Pubpdf: 環境を確認` を実行します。

エラーと警告は、VS Code では問題パネルに出ます。原稿の行が分かるものは、選ぶとその行へ移動します。Quarto の生のログは、出力パネルの Pubpdf で確認できます。

## エラーで止まるとき

| 表示 | 原因 | 対処 |
|---|---|---|
| `... が見つかりません`(原稿のパス) | コマンドに渡したパスの誤り | 実行場所からの相対パスを確認します |
| `章ファイル ... が見つかりません` | `chapters` のパスの誤り | 親 md からの相対パスを確認します |
| `章ファイル ... は md ではありません` | md 以外のファイルを指している | 拡張子が `.md`、`.markdown`、`.qmd` のファイルを指定します |
| `... は URL かネットワーク上の場所なので、読み込みません` | 章ファイル、ロゴ、文献のファイルに URL か `//サーバ/共有` の場所を指定した | ファイルを原稿のフォルダに置いて、相対パスで指定します |
| `本文に YAML と見なされる部分があるので、安全のため組みません` | 本文の `---` の行を、Quarto が設定と読んでしまう形になっている | `---` の行を `***` に変えるか、消します |
| `原稿と画像が別のドライブにある` | 章や画像が別のドライブを指している | 同じドライブに置きます |
| `画像 ... が見つかりません` | 画像のパスの誤り | 表示された行のパスを確認します |
| `参考文献のファイル ... が見つかりません` | `bibliography` のパスの誤り | 原稿からの相対パスを確認します |
| `ロゴのファイル ... が見つかりません` | `logo` のパスの誤り | 原稿からの相対パスを確認します |
| `ERROR: [object ErrorEvent]` | Mermaid の図を描くブラウザを起動できなかった | Mermaid を含む文書を同時に組んでいるときは、1 つずつ組みます |
| `embedding PDFs is currently not supported` | PDF の規格を指定した文書に、PDF の画像がある | PNG か SVG にします |
| `failed to parse BibLaTeX` | `.bib` の書き方の誤り | 括弧の閉じ忘れを確認します。エントリは波括弧で書きます |
| `... は画像として使えません` | 画像以外のファイルを指している | png、jpg、gif、svg、webp、pdf を指定します |
| `frontmatter の YAML を読めません` | YAML の書き方の誤り | 引用符の閉じ忘れや字下げを確認します |
| `... を上書きできません` | PDF を他のアプリで開いている | PDF を閉じて、もう一度実行します |
| `Quarto が見つかりません` | 未導入か、場所が不明 | 導入するか、`pubpdf.quartoPath`(VS Code)か `PUBPDF_QUARTO` で指定します |
| `レンダリングに失敗しました` | 組版中のエラー | 続く `error:` の内容を確認します |

: エラーの原因と対処 {#tbl-errors}

組版中のエラーが指す行番号は、原稿ではなく生成した Typst のファイルの行です。組版エラーで止まったときは、そのファイルが `.pubpdf/build/<原稿名>/<原稿名>.typ`(合本では `index.typ`)に残っています。

## 警告が出るとき

警告が出ても PDF は作られます。ただし、意図どおりの結果にならないことがあるので、内容を確認してください。

| 表示 | 意味 |
|---|---|
| `未知のキー ... は無視します` | キーの書き間違いの可能性があります |
| `... の値 ... は使えません` | 既定値で組みました |
| `frontmatter のキー ... は使いません` | Quarto の設定は書けません |
| `本文の途中の YAML は読みません` | frontmatter は原稿の先頭に書いてください |
| `リンク先 ... はこの文書に含まれない` | リンクを文字だけにしました |
| `リンク先の見出し ... が見つからない` | リンクを文字だけにしました |
| `章の pubpdf: は無視します` | 親 md に書いてください |
| `title と H1 の両方があります` | H1 を章題にしました |
| `章題がありません` | ファイル名を章題にしました |
| `UTF-8 で読めない文字があります` | 原稿を UTF-8 で保存し直してください |
| `日本語フォントが見つかりません` | フォントを導入するか、`fonts/` に置いてください |
| `Quarto ... は古い版です` | Quarto を更新してください |
| `Unable to resolve crossref` | `@fig-` などの参照先がありません |
| `フォント ... が見つかりません` | フォント名か読み込み先を確認してください。別のフォントで組みました |
| `フォントの場所 ... が見つかりません` | `font-paths` のパスを確認してください |
| `current font is not designed for math` | `font-math` には数式用のフォントを指定してください |
| `数式を変換できない` | 使えない LaTeX の命令があります。数式が LaTeX のまま出ています |
| `::: の囲みを閉じる行がありません` | 囲みの最後に `:::` の行を足してください |
| `引用やリストの中では改ページできない` | 引用、囲み、リストの外に書いてください。改ページは無視しました |
| `引用、囲み、リストの中では横向きにできない` | `.landscape` の囲みを外に出してください。縦のまま組みました |
| `参考文献のファイルに ... がない` | `.bib` のキーを確認してください。文字のまま出しました |
| `[@...] を文字のまま出します` | 文献を引用するときは `bibliography` を指定してください |
| `{{< meta ... >}} は使えません` | 使えるキーは `title`、`version` など 7 つです |
| `... に差し込む値が frontmatter にありません` | frontmatter に値を書いてください。空にしました |
| `abstract は文字で書いてください` | リストなどは使えません。概要は出しませんでした |
| `余白か綴じ代が大きすぎて本文が入らない` | `margin` や `book.gutter` の値を小さくしてください。既定の値で組みました |
| `... の図を読めません` | `tree` や `chart` などの図の書き方の誤りです。コードブロックのまま出しました。示された行を直してください |
| `図の label に ... は使えません` | `label` は `fig-` で始めてください |
| `段の幅が 30mm より狭くなる` | 段組みにせず 1 段で組みました。`columns` を減らすか余白を小さくしてください |
| `段組みの count に ... は使えない` | 2 段で組みました。`count` は 2 から 4 までです |
| `{.column} と他の内容が混ざっている` | 幅の指定を使わず、流れる段組みにしました |
| `表紙がないので logo は使いません` | `cover` に `simple` か `formal` を指定してください |
| `画像 ... に説明がない`、`Mermaid の図に題がない` | PDF/UA の代替テキストを「図」にしました。説明か題(`%%| fig-cap:`)を書いてください |
| `画像 ... は原稿のフォルダの外にあります` | 自分の原稿なら問題ありません。受け取った原稿では、意図しない画像でないかを確かめてください |
| `画像 ... は URL かネットワーク上の場所なので、読み込みません` | 画像の場所に灰色の枠を入れました。原稿のフォルダに保存して、相対パスで書いてください |
| `見出しに番号がないので、図表は通し番号にします` | `figure-numbering` の `chapter` と `section` には `numbering` の指定が必要です |
| `見出しに番号がないので、heading-format は使いません` | `numbering` に `chapter` か `decimal` を指定してください |
| `Mermaid の図が大きいので、文字が約 ...pt まで縮みます` | 図が版面の幅かページの高さに収まらず、文字が 6pt より小さくなります。図を分けるか、向きを変えるか、横向きのページに置いてください |
| `グリッド表の縦線の位置が罫線と合いません` | 示された行の `\|` の位置を、罫線の `+` に揃えてください。全角の文字は 2 文字分です |
| `HTML の表を閉じる </table> がない` | 表の最後に `</table>` を書いてください。表にせずに出しました |
| `HTML の表の中の画像は出しません` | 画像は Markdown の記法で、表の外に書いてください |
| `approval は role(役割)を持つ項目のリストで…` | `approval` の各項目に `role` を書いてください。承認欄は出しませんでした |

## 仕上がりがおかしいとき

| 症状 | 原因 | 対処 |
|---|---|---|
| 文字全体が細く、太字が効かない | Quarto 1.9 系と可変フォントの組み合わせ | Quarto を更新するか、`font` で BIZ UDPGothic などを指定します |
| 意図しない白紙 | 奇数ページ始まりがオン | `book.odd-start: false` にします。合本では既定でオンです |
| 数式の記号が崩れる | 数式用でないフォントを `font-math` に指定した | 数式用のフォントを指定するか、`font-math` を消します |
| プレビューが古いまま | PDF を作り直していない | 作成のボタンを押します。作り直すと表示位置を保ったまま更新します |
| 本文に `?@fig-名前` と出る | 参照先の図がない | 図の `{#fig-名前}` を確認します |
| Mermaid の図でエラーになる | ブラウザが見つからない | `Pubpdf: 環境を確認` でブラウザの有無を確認します |

## 既知の制限

- 番号付きの callout(`::: {#nte-名前 .callout-note}`)は、題の欄が少し縦に広くなります。
- VS Code のプレビューでは、文字の選択、リンクの移動はできません。必要なときは「他のアプリで開く」を使います。
- `aligned` などの複数行の数式で `\tag` を複数使うと、最後の1つだけが出ます。
- 引用、囲み、リストの中の見出しは、目次に載りません。
- 余白の注(`.column-margin`)には、まだ対応していません。本文の領域に出ます。
- 段の長さを揃えられないことがあります。図や表などを含む段組み、ページをまたぐ段組みの最後のページ、文書全体の段組みの最後のページです。
- 動作を確かめたのは Windows 11 だけです。
